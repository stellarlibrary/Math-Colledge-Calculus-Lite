# Limit Definition

## 📌 Core Formula
```latex
\lim_{x \to a} f(x) = L
```

## 🧠 What It Means
Describes the value a function approaches near a point.

## 💡 Intuition
Focus on behavior near the point, not exactly at it.

## 🔍 Example
lim x→2 (x²) = 4

## ⚠️ Common Mistakes
Plugging in directly when undefined
